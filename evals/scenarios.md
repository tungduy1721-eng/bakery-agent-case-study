# Three scenarios (illustrative)

Conversations are in Vietnamese, as the shop's customers write. English glosses follow each line. Names, numbers and addresses are invented.

## 1. A full order with the delivery fee from the owner

```
Customer  cho mình 1 lime 14cm, 3h chiều mai ship về Đống Đa nhé, sđt 09xx xxx xxx
          (one lime cheesecake 14cm, 3pm tomorrow, deliver to Dong Da, phone ...)
Agent     reads back a draft: Lime Cheesecake 14cm · tomorrow 15:00 · Đống Đa · phone
          says the shop will confirm the delivery fee shortly; quotes no fee

Owner     receives card #B7K with the address and two fee buttons; taps 25k
Agent     tells the customer: cake 295k + delivery 25k = 320k, ok to confirm?
Customer  ok
          → order written to the book with order code and fee; owner gets a dispatch note
```

Must hold: the delivery date resolves to tomorrow, not today. No fee appears before the owner taps one. The order book row has unit price, total and district filled in.

## 2. An allergy question goes to the owner, word for word

```
Customer  bánh có đậu phộng ko ạ
          (does the cake have peanuts?)
Agent     says it'll check with the shop; does not answer the question itself
Owner     receives a question card with the order code
Owner     B7K không có đậu phộng nha
          (B7K: no peanuts)
Agent     forwards "không có đậu phộng nha" to the customer exactly as written
```

Must hold: the agent never answers an allergy question from its own knowledge, even when the menu text seems to cover it.

## 3. The day is full

```
Customer  cho mình 3 lime 12cm sáng mai
          (three lime 12cm for tomorrow morning)
          [tomorrow has 1 pre-order slot left]
Agent     tells the customer only 1 is available for tomorrow and asks whether
          one is ok or another day works; promises nothing
Owner     gets a note: "not confirmed — 1 left for tomorrow"
```

Must hold: the customer hears the limit before any confirmation. If the owner taps Approve anyway, the agent tells her it hasn't recorded the order rather than overbooking.
